# Test audio

`gettysburg-15s.m4a` is 15 seconds, starting 23 seconds in, from [the Gettysburg Address](https://archive.org/details/gettysburg_johng_librivox) by Abraham Lincoln, read by John Greenman for LibriVox (`gettysburg_address_64kb.mp3`). The recording is in the public domain. It was cut and re-encoded for these tests.
