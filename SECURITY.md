# Security

Minutes records conversations, so security problems matter a lot here. Thank you for reporting them carefully.

## Reporting a problem

Please don't open a public issue. Report it privately through GitHub instead: go to the [Security tab](https://github.com/RossLopez/minutes/security), choose **Report a vulnerability**, and describe the problem and how to reproduce it.

The aim is to reply within a week. Once it's fixed, the release notes credit you, unless you'd rather not be named.

Please don't include recordings, transcripts or notes from real meetings in a report. If you need a recording to show the problem, make a new one.

## What counts

For example:

- Meeting audio, transcripts, notes, summaries or chats leaving the Mac in a way the user didn't choose.
- Minutes contacting any server other than the ones in the README's privacy section.
- Content from meetings written to logs.
- An update that installs without a valid signature.
- Files in `~/Minutes` readable by other users of the Mac when they shouldn't be.

## Supported versions

Fixes go into the latest release. Please check that the problem is still there in it before reporting.
